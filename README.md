# POC Integra Microsoft Teams
**Objetivos**
* Incluir eventos de calendário conforme BD local no Teams
* Refletir alteração local no calendário do Teams
* Remover do calendário do Teams se excluso localmente

Utilizando API do Microsoft Graph conforme documentação oficial e SDK.  
Doc em [learn.microsoft.com](https://learn.microsoft.com/en-us/graph/api/resources/calendar-overview?view=graph-rest-1.0)
